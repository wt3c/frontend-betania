# Landing Page - Maria Betania Terapeuta

Landing page profissional desenvolvida para a terapeuta Maria Betania, focada em conversão para agendamentos via
WhatsApp.

## 🚀 Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 (Variáveis CSS, Flexbox, Grid)
- JavaScript Vanilla (Sem dependências)
- Design Responsivo (Mobile-first)


## 🛠️ Como Personalizar

### 1. Google AdSense

Para ativar os anúncios, edite o arquivo `index.html` e procure pelos comentários `<!-- AdSense Code Here -->` ou blocos
de script comentados no `<head>`. Insira seu código fornecido pelo Google AdSense nesses locais.

### 2. Imagens

As imagens atuais são placeholders do Unsplash. Para usar fotos reais:

1. Adicione suas imagens em uma pasta `/img` (crie a pasta se necessário).
2. Atualize os atributos `src` nas tags `<img>` no arquivo `index.html`.

### 3. Links de Contato

Verifique se o número do WhatsApp está correto em todos os links:
`https://wa.me/5521988070905`

## 📦 Como Fazer Deploy

Este é um site estático, então você pode hospedá-lo gratuitamente em diversos serviços:

- **GitHub Pages**: Basta subir os arquivos para um repositório e ativar o Pages nas configurações.
- **Vercel / Netlify**: Arraste a pasta do projeto para o dashboard ou conecte com seu Git.
- **Hospedagem Tradicional**: Faça upload dos arquivos `index.html`, `styles.css` e `script.js` para a pasta
  `public_html` do seu servidor via FTP.
